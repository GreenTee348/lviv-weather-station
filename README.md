# Lviv Weather Station

A modern weather dashboard for Lviv, Ukraine, built as a lightweight app-style web page. It pulls live weather data from the Open-Meteo API and displays current conditions, hourly forecasts, and a 7-day outlook in a clean, responsive interface.

## What it does

This project shows real-time weather for Lviv using live API data. It gives users an at-a-glance picture of:

- Current temperature and feels-like temperature
- Humidity
- Wind speed
- Rain and precipitation
- Atmospheric pressure
- Cloud cover
- Sunrise and sunset times
- Hourly weather forecast
- 7-day forecast
- Weather status summary for the city

## Features

- Real weather data from Open-Meteo
- Lviv-specific coordinates
- App-style dark UI
- Responsive layout for desktop and mobile
- Temperature unit toggle between Celsius and Fahrenheit
- Refresh button for manual updates
- Hourly weather cards
- 7-day forecast cards
- Lightweight single-page implementation

## Location

- City: Lviv, Ukraine
- Coordinates: 49.8397, 24.0297
- Timezone: Europe/Kyiv

## Tech stack

- HTML
- CSS
- Vanilla JavaScript
- Open-Meteo API

## How to run

1. Open `index.html` in a browser.
2. The app will automatically load the latest weather data for Lviv.
3. Use the dropdown to switch between °C and °F.
4. Click Refresh to reload the information.

## Notes

This app is intended as a lightweight weather dashboard and does not require an API key for the Open-Meteo service used in the project.

## Project purpose

The goal of this project is to provide a realistic, modern weather station experience for a specific city, while keeping the implementation simple, free, and easy to run locally.
